Graph Sentinel: AI-Powered Anomaly Detection and Threat Intelligence in Network Traffic Using Graph Neural Networks

This research presents Graph Sentinel, an AI-powered network security framework that models network traffic as graph structures and applies Graph Neural Networks (GNNs) for real-time anomaly detection and threat intelligence. The system identifies complex attack patterns invisible to traditional statistical methods by exploiting relational dependencies between network nodes and edges.
